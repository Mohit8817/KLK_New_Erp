# KLK Ventures — ERP System

Enterprise Resource Planning system for **KLK Ventures Private Limited**. Built with **React 19 + TypeScript** on **Vite**, styled with **Tailwind CSS v4** on the unified token core.

## Core Manufacturing Lines

1. **Lithium Battery Packs** — Advanced energy storage systems, BMS integration, module assembly, and life-cycle quality validation.
2. **Solar Water Pumps** — Submersible and surface solar pump controllers, BLDC motor drives, and agricultural solar irrigation setups.
3. **Solar Street Lights** — Integrated all-in-one & split solar street lighting systems with intelligent dusk-to-dawn sensors.
4. **Solar Panels** — High-efficiency mono PERC and bifacial PV modules with automated stringing, lamination, and EL testing.
5. **Rooftop Systems** — On-grid, off-grid, and hybrid solar rooftop turnkey installations for residential, commercial & industrial facilities.
6. **Metal Structure** — Hot-dip galvanized mounting structures, tracking structures, rooftop ballasted and tin-shed clamps fabrication.

## Getting Started

From this folder (`React/`), run:

1. **Install dependencies**
   ```bash
   npm install
   ```

2. **Start the development server**
   ```bash
   npm run dev
   ```

3. **Create a production build**
   ```bash
   npm run build
   ```

4. **Preview the production build locally**
   ```bash
   npm run preview
   ```
